# Позитившар — демонстрационный сайт для Vercel

**Готовый адаптивный проект на React + Vite** для магазина воздушных шаров «Позитившар» (Уфа).

> Важно: это **независимый неофициальный концепт**, созданный без подтверждения сотрудничества с магазином. Сайт не принимает оплаты, не отправляет заявки и не выдаёт архивные цены или макетные иллюстрации за текущий ассортимент.

## Что внутри

- Многостраничная по содержанию, но одностраничная по навигации адаптивная витрина.
- Авторские SVG: главный праздничный коллаж, иллюстрации для **18 товаров**, мини-сцены, графика доставки, декоративная схема местоположения, пиктограммы. Никаких чужих фотографий.
- Фильтры по товарной категории, поиск, подбор по поводу, кнопка «Показать ещё».
- Рабочая **подборка товаров**: добавление нескольких единиц, удаление, очистка, копирование запроса для магазина.
- Рабочий **конструктор набора**: повод, 6 палитр, от 3 до 21 шара, фольгированное сердце, праздничная цифра, надпись, способ получения, визуальное SVG-превью и копирование запроса.
- Плавные появления блоков и анимация элементов (с поддержкой `prefers-reduced-motion`).
- FAQ-аккордеон, контакты, ссылка на отзывы 2ГИС.
- Минимум рамок и **никакой декоративной нумерации разделов**.
- В футере тонкая рамка со ссылкой на Telegram разработчика: **[@milmak11](https://t.me/milmak11)**.

## Развёртывание локально

Потребуется Node.js версии 20.19+ или 22.12+ и интернет для первоначальной установки npm-пакетов.

```bash
npm install
npm run dev
```

Затем откройте адрес, показанный Vite (обычно `http://localhost:5173`).

Создание production-сборки:

```bash
npm run build
npm run preview
```

Vite создаст папку `dist`.

## Развёртывание на Vercel

1. Создать GitHub-репозиторий, загрузить в него **содержимое** этого архива (папку `src`, `public`, `index.html`, `package.json`).
2. В Vercel выбрать **Add New → Project**, импортировать репозиторий.
3. Framework Preset: **Vite** (как правило, распознаётся автоматически).
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Нажать Deploy.

Поскольку это один React-маршрут `/` с якорными разделами, специальная серверная конфигурация не требуется.

**Идея адреса:** `pozitivshar-ufa-demo.vercel.app`. Доступность адреса нужно проверить в Vercel.

## Важные ограничения демоверсии

- Все **18 названий и цен** взяты из прайса в карточке 2ГИС, который, согласно проверке, обновлялся **13 марта 2026 года**. Цены **не подтверждены на ноябрь 2026 года**. Они выводятся с оговоркой на сайте.
- Иллюстрации товаров — стилизованные SVG, **не фотографии настоящих композиций** и не точное изображение товара.
- Количество и цены не рассчитываются как окончательная сумма заказа; нет оплаты, корзины для оформления покупки и реального учёта остатков.
- Выбор товаров и конструктор формируют **локальный текст запроса**, который посетитель может вручную скопировать. Нет Telegram-бота, backend, базы данных и отправки пользовательских данных куда-либо.
- Ссылки на телефон, Telegram, VK и 2ГИС ведут на **публичные контакты** компании. Для полноценного официального сайта сначала нужно подтвердить у владельца актуальность этих каналов.
- Вся демоверсия закрыта от индексации мета-тегом `noindex` и `robots.txt`.
- Необходимо получить разрешение компании перед использованием официальных логотипов, реальных фотографий, точных цен, принятия заявок от имени бизнеса или выдачи сайта за официальный.

### Статический предпросмотр

`preview-static.html` можно открыть как **снимок дизайна** без сборки. В папке `previews/` также лежат PNG-скриншоты первого экрана на компьютере и смартфоне. Он позволяет посмотреть текст и SVG в браузере, однако **интерактивные действия в этом предварительном HTML не работают**. Для работающего сайта используйте `npm run dev` или деплой на Vercel.

## Проверка

- Синтаксис `data.js`, `illustrations.jsx` и `App.jsx` проверен посредством TypeScript JSX transpilation.
- Пререндер JSX для статического предпросмотра успешен: 18 карточек и более 100 встроенных SVG-элементов на странице.
- В этой изолированной среде **npm install не завершился** из-за отсутствия доступа к registry.npmjs.org (`EAI_AGAIN`); поэтому сборку Vite и интерактивное тестирование в живом браузере здесь подтвердить не удалось. При доступе к npm развёртывание выполняется по обычной процедуре выше.
